# Beyond the Dark

**Beyond the Dark** - пиксельный 2D платформер на Python и Pygame CE про приключение храброго героя Dave, который жаждит заполучить сокровища подземелья, но ему необходимо будет преодолеть множество препятствий и победить злых монстров!


## Возможности

- **Три уровня**: «Лес» → «Пещера» → «Финал».
- **Три сердца** у героя. После урона примерно 1.5 секунды неуязвимости.
- **Монеты и звёзды**: на игру приходится 25 монет. За уровень дают 1 звезду при 50% собранных монет, 2 — при 80%, 3 — при 100%; максимум 9 звёзд.
- **Лес**: рычаг опускает мост через пропасть, есть тайник, шипы и монеты на платформах.
- **Пещера**: скелеты-патрульные, мост, хилки и густая тьма.
- **Финал**: дракон-босс, атакует пламенем вблизи и обвалом сталактитов по всей арене.
- **Тьма уровней**: чем глубже, тем темнее; герой полон решимости, поэтому вокруг него постоянный круг света.
- **Настройки**: громкость музыки и звуков (запоминается между запусками), разрешение от 800×600 до 1920×1080 и режим окна — оконный, без рамок, полный экран.

## Управление

| Действие | Клавиши |
| --- | --- |
| Идти влево / вправо | ← / → или A / D |
| Прыжок | ↑ / W / Пробел |
| Удар мечом | Левая кнопка мыши |
| Дёрнуть рычаг и опустить мост | E рядом с рычагом |
| Выйти в меню | Esc |
| Перезапустить уровень после смерти | R или кнопка «ЗАНОВО» |

## Запуск

Нужен **Python 3.14 или новее** (проверено на Python 3.15.0 и Pygame CE 2.5.8). Готовые PNG и MP3 уже лежат в `assets/` и `music/`, пересобирать ассеты не нужно.

### Windows

Открой PowerShell в корне репозитория:

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe .\Beyond-the-Dark\main.py
```

При повторных запусках достаточно последней строки.

### Ubuntu / Linux

Открой терминал в корне репозитория:

```bash
sudo apt update
sudo apt install -y python3-full
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python Beyond-the-Dark/main.py
```

При повторных запусках тоже достаточно последней строки.

## Зависимости

Игре нужен только Pygame CE — он указан в `requirements.txt`:

```
pygame-ce==2.5.8
```

**Pillow** нужен только скриптам подготовки и пересборки ассетов (`prepare_assets.py`, `prepare_coin.py` и т.п.). Он вынесен в отдельный файл `requirements-dev.txt`:

```
-r requirements.txt
Pillow==13.0.0
```


## Сохранения

Прогресс (лучшие монеты и звёзды по уровням, громкости музыки и звуков) хранится в `save.json` рядом со скриптами игры. Файл создаётся автоматически и добавлен в `.gitignore`. Удаление файла сбрасывает прогресс к нулю.

## Примечания

- Игра отрисовывается в 800×600, в 60 FPS чтобы запускалось вообще везде, и масштабируется под окно без сглаживания, поэтому пиксель-арт остаётся чётким.
- Уровни 1 и 2 шире экрана: камера следует за игроком, фон прокручивается.
- На уровнях 1 и 2 спрятаны секретные зоны — при входе появляется сообщение «СЕКРЕТНОЕ МЕСТО НАЙДЕНО!».
